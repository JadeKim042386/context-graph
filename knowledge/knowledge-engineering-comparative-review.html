Knowledge Engineering Comparative Review

Reviewed on 2026-09-12 · Standards, research, and the current project were compared using the same evidence-oriented criteria.

Summary: the project is directionally aligned with evidence graphs, provenance, and retrieval-augmented generation evaluation. The main gaps are independent gold data, media-aware locators, automatic validation, and an operational graphify/performance runner.

Review criteria

  • Can each claim be connected to a precise source span or media locator?
  • Is provenance recorded in a way that supports auditing and reproducibility?
  • Can graph structure and constraints be validated automatically?
  • Are retrieval quality and answer-generation quality evaluated separately?
  • Do the records support text, images, video, and audio rather than text alone?

Problems found in the current project

  1. Operational evidence and synthetic fixtures are mixed, so benchmark improvements do not yet prove production improvement.
  2. Locators are mostly text-centric and do not yet provide a consistent frame, timestamp, page, or region model for media.
  3. Structural validation is still partly manual; schema checks should become executable gates.
  4. The search strategy makes stronger claims than the current measurements support.
  5. The graphify and performance runners are not yet connected to one repeatable operational evaluation path.

Iteration plan

  1. Extend the evidence schema with source URI, media type, locator, capture time, extraction method, and confidence.
  2. Create an independent gold set that is not used to tune retrieval or answer prompts.
  3. Run paired operational measurements for the baseline and the proposed strategy on the same cases.
  4. Publish retrieval, generation, latency, cost, and failure metrics as separate dimensions.
  5. Keep source links and implementation status next to each design decision so later reviews can distinguish implemented, partial, and hypothetical behavior.

Judgment

The design direction is consistent with the cited standards and RAG evaluation research. It should not yet be described as fully validated. Independent gold data, media locators, automatic graph validation, and an operational graphify runner are required before performance claims become reliable. The biological-search component remains a research hypothesis until it is tested with paired production measurements.
